## 1. Add a custom domain

Point your own domain at a deployment instead of using the default one.

## 2. Update deployment size

Scale the compute and memory behind a deployment up or down.

## 3. Pause or resume a deployment

Suspend a deployment you are not actively using, and bring it back without
losing data.

## 4. Reset a database

Empty a database and rebuild it from its current schema — useful for resetting
a staging environment back to a known state.
