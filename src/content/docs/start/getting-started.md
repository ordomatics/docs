## 1. Onboard a project

Onboarding creates a **project** — `demo` in this example — with a `main` branch
and a `demo` database already on it.

## 2. Add a database

Create a second database, `demo-staging`, on the same `main` branch.

## 3. Create an environment

An environment serves every database that exists on a branch at the time it is
created. An environment created from `main` now serves both `demo` and
`demo-staging`.
