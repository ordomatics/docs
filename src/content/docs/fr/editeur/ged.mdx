Un client **Smartacus Pro** reçoit sa propre base de données, avec son équipe
configurée dedans. Chaque membre édite ses documents dans Smartacus, comme
dans les autres parties de ce tutoriel — mais ils sont aussi rangés
automatiquement dans le back-office de l'entreprise, et l'administrateur du
cabinet peut tous les retrouver, sans jamais pouvoir les modifier.
