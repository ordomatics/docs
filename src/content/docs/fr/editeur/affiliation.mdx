Vous connaissez des personnes, des entreprises ou des services qui gagneraient
à utiliser l'éditeur ? Devenez **affilié** : vous touchez une commission sur
chaque recharge de crédits des clients que vous parrainez, versée sur votre
compte **Wave**.

## B.1 Devenir affilié

1. Ouvrez **Mon compte** : la carte **Affiliation** propose **Vendre ce
   logiciel**.
2. Expliquez en quelques mots votre démarche (qui vous comptez accompagner,
   comment).
3. Indiquez le **numéro Wave** qui recevra vos commissions, s'il n'est pas déjà
   enregistré.
4. Cliquez sur **Envoyer** : votre demande passe **En attente**.

<Clip src="bonus-1-devenir-affilie.mp4" voice caption="Envoyer une demande d'affiliation (avec voix off : lancez la vidéo avec le son)" />

L'équipe Smartacus étudie votre demande et vous prévient par e-mail dès
qu'elle est approuvée.

## B.2 Parrainer avec votre lien

Une fois approuvé, **Mon compte** affiche votre **Solde parrainage**. Cliquez
sur **Voir** pour ouvrir votre espace affilié, où se trouve votre **lien de
parrainage**. Cliquez sur **Copier**, puis partagez-le (WhatsApp, e-mail,
réseaux sociaux…).

Les personnes qui créent leur compte **en ouvrant ce lien** deviennent vos
filleuls. À **chaque recharge** de crédits de l'un d'eux, vous recevez un
pourcentage du montant rechargé.

:::tip[Le lien d'abord]
Le parrainage est enregistré à la création du compte : demandez à vos filleuls
d'ouvrir votre lien **avant** de s'inscrire, sinon le compte ne vous sera pas
rattaché.
:::

## B.3 Retirer vos commissions via Wave

Une commission reste **en attente** quelques jours, le temps de valider la
recharge, puis devient **payable** et s'ajoute à votre **solde payable**.

1. Dans votre espace affilié, vérifiez votre numéro Wave (bouton **Modifier**
   pour le changer, puis **Enregistrer**).
2. Cliquez sur **Retirer via Wave** et indiquez le montant.
3. Cliquez sur **Confirmer le retrait** : le montant est envoyé sur votre
   compte Wave.

<Clip src="bonus-2-espace-affilie.mp4" voice caption="L'espace affilié : lien de parrainage, solde et retrait (avec voix off ; retrait annulé dans la démonstration)" />

Un **solde minimum** est nécessaire pour retirer : tant qu'il n'est pas
atteint, l'espace affilié vous l'indique. Vos derniers retraits s'affichent
avec leur état : **En cours**, **Payé** ou **Échoué**. Un retrait échoué n'est
pas perdu : le montant reste dans votre solde.
