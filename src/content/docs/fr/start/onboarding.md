## 1. Envoyez un message

Écrivez-nous sur [WhatsApp](https://wa.me/221773649575). C'est le formulaire
d'inscription — il n'y a rien à remplir.

Nous vous demanderons le nom de votre entreprise, votre pays d'activité, et ce que
vous souhaitez gérer en premier (stocks, facturation, clients, ou tout).

## 2. Nous provisionnons

Votre instance Odoo 18, sa base de données et son stockage sont créés
automatiquement. Vous recevez votre propre adresse et un accès administrateur.

Le degré d'isolement dépend de votre formule — voir [Formules](/fr/reference/plans/).

## 3. Vous travaillez

Posez vos questions au système, émettez des factures, suivez vos stocks. Vos
données vous appartiennent dès le premier message.

:::note
Vous venez d'un Odoo existant ? C'est le même Odoo dessous : votre base actuelle
peut généralement être reprise. Indiquez-nous votre version et vos modules.
:::
